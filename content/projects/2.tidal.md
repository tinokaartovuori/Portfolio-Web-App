Twelve years of readings from forty buoys is about ninety million points. The
previous tool paged through it and researchers stopped using it, because you
cannot see a pattern through a page boundary.

The fix was to stop sending rows. The server precomputes tiles at several zoom
levels and the client only ever holds what is on screen, so panning across a
decade costs the same as panning across a week.
